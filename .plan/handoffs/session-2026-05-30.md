## Decisions & Rationale
1. **Option C for default page** — Removed `/daily` entirely rather than aliasing. Cleanest URL surface; user accepted breaking old bookmarks.
2. **Full-bleed cards on mobile** — `rounded-none sm:rounded-xl` with `px-0 sm:px-4` container gives maximum screen real estate on phones while preserving desktop aesthetics.
3. **DataTable folder + renderers extraction** — Separates presentation shell from cell-rendering logic. Makes the component easier to navigate and test.
4. **LAN auto-detect in Makefile** — Zero-config for the happy path. Falls back to localhost silently when offline. `VITE_DEV_HOST` override available for edge cases.
5. **text-sm base** — Single `body` class change affects everything. Removed redundant explicit classes to avoid drift. Kept buttons at their existing sizes.
6. **Calendar as monthly blocks** — Each month is a self-contained `col-span-7` section with its own sticky label and 7-column grid. Gray padding fills empty spaces. Natural CSS sticky stacking for month labels. This avoids the complexity of continuous week strips and keeps each month visually coherent.
